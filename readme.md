# 🎓 Selecta — School Recommendation System

This Streamlit app recommends the nearest suitable schools based on your ASPD and report card scores.  
It uses the K-Nearest Neighbors (KNN) algorithm to find the closest match among schools in each region.

## 🚀 Features
- 5 regions: Yogyakarta, Sleman, Bantul, Kulonprogo, Gunungkidul
- KNN-based school recommendation
- Adjustable number of nearest neighbors (Top-K)
- Clean, responsive Streamlit UI

## ▶ How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
